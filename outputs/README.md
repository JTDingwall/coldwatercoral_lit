# Cold-water coral sedimentation literature outputs

Final screened bibliographic outputs are organized by evidence tier:

- `tier_a/`: 95 high-confidence core documents.
- `tier_b/`: 166 wider-berth documents retained under the Tier B policy.
- `tier_a_plus_b/`: 261 deduplicated documents combining both tiers.

Each tier includes metadata and RIS exports suitable for bibliographic review. The combined folder also contains the reviewed multi-sheet Excel workbook.

Only final document records are included in the RIS files. Citation-chain candidates, uncertain records, excluded records, and discovery webpages are omitted.
