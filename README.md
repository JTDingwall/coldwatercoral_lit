# Cold-water coral literature search

Simple shared repository for the AI-assisted source-discovery project on cold-water corals, sponges, and sediment-related disturbance.

Stage 4 production discovery is complete in [`step_4/`](step_4/). Current work is
in [`step_5/`](step_5/), which contains the frozen screening protocol, controlled
vocabulary, calibration workflow, prompts, schemas, and screening QA materials.

The scientific synthesis is outside the scope of this repository. This repository is for source discovery, provenance, screening support, and reproducibility.
